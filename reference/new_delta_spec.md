# Create a delta spec

Create a delta spec

## Usage

``` r
new_delta_spec(fields, abs_tol = 0, rel_tol = 0, method = "exact")
```

## Arguments

- fields:

  Fields to compare.

- abs_tol:

  Absolute tolerance.

- rel_tol:

  Relative tolerance.

- method:

  Comparison method.

## Value

A validated `DeltaSpec` object.
