# aRtifacts: schema-agnostic dataset observability engine

Lightweight S7-based snapshot, diff, and rule engine for longitudinal
dataset observability. The core engine is schema-agnostic and works with
any keyed tabular data using a topology-first rule model (`A0` to `A7`).
Domain-specific rules are intended to live in companion packages.
